#  Muhammad Jasil EK (MXD) Portfolio

A modern, responsive personal portfolio website showcasing my work in **Python Development, AI/ML, Full Stack Development, Graphic Design, and Video Editing**. Built to highlight projects, skills, experience, achievements, and creative work through an interactive and visually engaging experience.

##  Features

* Responsive design for mobile, tablet, and desktop
* Interactive UI with smooth animations
* Python & AI/ML project showcase
* Web Development project gallery
* Graphic Design portfolio categories
* Video Editing portfolio sections
* Skills, Experience, and Achievements sections
* Dynamic routing and navigation
* SEO-friendly structure
* Performance optimized with Vite
* Modern UI built with Tailwind CSS and Framer Motion

##  Tech Stack

* React.js
* Vite
* Tailwind CSS
* Framer Motion
* React Router DOM
* React Scroll
* ESLint

##  About

**Muhammad Jasil EK (MXD) Portfolio** is a modern, responsive personal portfolio website designed to showcase my journey as a Python Developer, AI/ML enthusiast, Graphic Designer, and Video Editor.

The platform highlights my technical projects, web development work, creative designs, video editing portfolio, professional experience, skills, achievements, and certifications in a structured and interactive format.

Built using React, Vite, Tailwind CSS, Framer Motion, and React Router, the website delivers a smooth user experience with responsive layouts, dynamic navigation, engaging animations, and optimized performance across devices. It serves as a central hub where recruiters, collaborators, and clients can explore my work, learn about my expertise, and connect with me professionally.

The portfolio reflects my multidisciplinary approach to technology and creativity, combining software development, artificial intelligence, design thinking, branding, and digital content creation. It represents my commitment to building meaningful digital experiences while continuously learning, improving, and growing as a developer and creator.
